  • The message log has role="log" and tabindex="0"
  • New messages announced via aria-live="polite" — no focus move
  • ↑ / ↓ moves between messages and interactive elements inside them
  • Enter activates a focused link or button inside the log
  • Interactive items inside the log use tabindex="-1" so Tab skips them

General behaviour rules

  • On open: focus moves to dialog; screen reader announces "Sage - Your AI help assistant, dialog"
  • Focus trap: Tab / Shift+Tab cycles only within steps 1–9
  • On close: focus returns to the owl trigger button on the page
  • Escape key: closes panel and returns focus to trigger
